# 💸 Life After Salary

**Life After Salary** is a financial-life simulation game that helps young professionals understand how everyday decisions impact their finances, stress levels, investments, credit score, and long-term wealth.

🔗 Live Demo: https://life-after-salary.vercel.app/

---

## 🎯 About The Project

Many people start earning without fully understanding how salary translates into real-life financial outcomes.

Life After Salary simulates 12 months of adult life where players make monthly decisions related to:

* 🏠 Housing & Rent
* 🍔 Food & Lifestyle
* 💳 Credit Card Payments
* 📈 Investments
* 🎲 Random Life Events

The goal is to maximize wealth, maintain a healthy credit score, manage stress, and make smart financial decisions.

## ✨ Features

### 👤 User Authentication

* Secure Sign Up
* Login
* Persistent Sessions
* Firebase Integration

### 🌆 City-Based Simulation

Choose from major Indian cities:

* Mumbai
* Pune
* Bengaluru
* Hyderabad
* Delhi

Each city has different:

* Rent Costs
* Living Expenses
* Cost Multipliers

### 💰 Salary-Based Gameplay

Players enter their actual monthly salary and experience realistic budgeting decisions.

### 📈 Financial Metrics

The game tracks:

* Net Wealth
* Savings
* Investments
* Credit Score
* Stress Level
* Scam Risk
* Monthly Score

### 🎲 Random Events

Unexpected situations appear throughout the year:

* Medical Emergencies
* Scams
* Bonuses
* Investments Opportunities
* Lifestyle Expenses

### 📊 Year-End Summary

At the end of 12 months players receive:

* Final Wealth
* Total Income
* Total Expenses
* Credit Score
* Stress Analysis
* Overall Financial Score

Players can:

* Share Results
* Start New Game
* Replay Different Scenarios

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/rutujas11/Life-After-Salary.git
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build Project

```bash
npm run build
```
